二、观测似然

设 T 为事件时间，a_i 为入组时间，保留条件 T_i > a_i。假设源总体中 T 与 entry 独立，且删失/检查机制可忽略。令 S(t)=P(T>t)。对区间观测 (L_i,R_i]，使用有效区间

  I_i^+ = (max(L_i,a_i), R_i]。

其条件似然贡献为 P(I_i^+)/S(a_i)；exact event t_i 的贡献为 f(t_i)/S(a_i)。R_i=Inf 即右删失。必须有 R_i>a_i，exact event 也必须严格晚于 entry。没有要求拟合 entry 的分布。

仅裁剪 L_i 为 max(L_i,a_i) 还不够，因为 -log S(a_i) 会耦合树节点，原有 observed allocation 不能单独提供正确的截断校正。

三、ghost augmentation 和 allocated expected count

对每个保留个体，引入在一次成功接受 T>a_i 之前的 K_i 个虚拟拒绝事件：

  Pr(K_i=m | a_i, Theta) = S_Theta(a_i) F_Theta(a_i)^m, m=0,1,...
  E(K_i | a_i, Theta) = F_Theta(a_i)/S_Theta(a_i)。

拒绝事件 Z_ij 条件分布为 P_Theta(. | T<=a_i)。将拒绝事件积分并对 m 求和，得到 P_Theta(I_i^+) sum_m F_Theta(a_i)^m = P_Theta(I_i^+)/S_Theta(a_i)。exact event 把 P(I_i^+) 换成 f(t_i)。这个构造保留原条件似然，不需要观测被截掉的真实人数。

在迭代 k，对任意树节点 A：

  Ntilde_A^(k) = sum_i [w_iA^(k) + g_iA^(k)]，
  w_iA^(k) = P_k(A intersect I_i^+)/P_k(I_i^+)（区间观测），
  w_iA^(k) = 1(t_i in A)（exact event），
  g_iA^(k) = P_k(A intersect (0,a_i])/S_k(a_i)。

代码允许非零 lower support s0；此时把 (0,a_i] 换成 support 内的区间。a_i<=s0 没有截断效应。

ghost 分配必须对所有 retained observations 添加，包括 exact events，且不能受原 observed-interval membership 的筛选限制。节点 A 可以完全不与 I_i^+ 相交，却仍可能收到 ghost count。

根节点的总数不再是 n，而是：

  Ntilde_root^(k) = n + sum_i F_k(a_i)/S_k(a_i)
                  = sum_i 1/S_k(a_i)。

兄弟节点 counts 相加等于父节点 count。这个量是辅助模型下的期望总数，不应直接称为估计的实际招募总体人数。

四、保留的 Beta 形式和实际 M-step

对于父节点的左右子节点 A、A'，分支概率 theta_A 的先验为 Beta(alpha_A,alpha_A')。增广 complete-data 的 conditional posterior 是 Beta(alpha_A+N_A,alpha_A'+N_A')。以 expected counts 构造的 Q 函数为：

  Q(Theta | Theta_k) = sum_pairs [
    (alpha_A + Ntilde_A^(k) - 1) log(theta_A)
    + (alpha_A' + Ntilde_A'^(k) - 1) log(1-theta_A)
  ] + constant。

两侧 shape 都大于 1 时，精确的内部 MAP 更新为：

  theta_A = (alpha_A + Ntilde_A - 1) /
            (alpha_A + alpha_A' + Ntilde_A + Ntilde_A' - 2)。

代码为保持原算法兼容，保留旧的 boundary rule：令分母 D 为上式分母；D>1e-300 时把比例 clip 到 [0,1]，否则 theta_A=0.5。这是 mode-style update，不是 posterior mean。当 shape<=1 时，尤其 D<=0 的 0.5 fallback，不一定最大化 Q。因此不能宣称当前实现满足一般的精确 MAP-EM 单调收敛保证。若今后要严格对接论文在 [epsilon,1-epsilon] 上的理论，需要另行实现真正的约束 argmax，并单独讨论与旧输出兼容性的冲突。

观测后验在边际上并不是各节点独立 Beta 的乘积；准确表述是增广 complete-data conjugacy，以及用期望计数构造 Q 后仍保留相同的节点代数形式。把 expected counts 填入 Beta 并不自动给出精确的 observed-data Bayesian posterior。

五、代码执行逻辑

1. R/PT.R: survPT(..., entry=0)，新参数放在末尾；接受非负有限 scalar 或长度 n 的 vector。保持原位置参数兼容。
2. R/native-interface.R 和 Rcpp wrappers: native R 接口 SurvPT(..., entry=NULL) 仍可用旧的 10 个参数调用；内部原生调用已增加 entry。
3. src/main.cpp、src/PT.h、src/PT.cpp: 校验 entry，裁剪非 exact 区间。support 内有正截断时要求 allocated=1。
4. 初始化：用原初始基分布计算 observed counts 和 ghost counts；无界支持先以 body/tail 先验均值各 0.5 计算分配。必须在 early stopping 判断之前添加 ghosts。树由该初始化决定，在 EM 中固定。
5. prepare_observation_cache: 固定树与基参数后缓存 observation kernels、entry 以下 kernels、entry 以上 kernels。S(entry) 直接积分 entry 以上质量，避免用 1-F(entry) 的抵消误差。
6. update_expected_allocations / add_truncation_allocations: 每次 E-step 全部用上一轮的质量计算 observed+ghost counts；leaf counts 向父节点汇总。
7. re_allocation: 把新的总 counts 代入原分支更新规则；body/tail split 也用同样的 counts。
8. log_likelihood: 每条记录扣除 log S(entry)。LogLik 和 LogLik_Trace 均为 conditional observed log likelihood，不含 prior 项。
9. 停止条件仍是 terminal masses 的 L2 变化 <= EM_tol。Allocations 返回 observed+ghost counts，根节点可大于 n。
10. 无界支持仍保留 unresolved tail。tau 是有效观测区间的最大有限端点；entry 可以通过裁剪扩大 tau。S(tau)=p_tail；tau 之后的有限 t 不确定 tail shape，返回 NA。

六、a_i=0 为什么退回原算法

在原模型的非负连续支持下，F(0)=0、S(0)=1：ghost counts 全部为 0，区间不变，条件似然等于原似然，根 count=n。代码通过 has_truncation=false 跳过额外运算，保留原初始化和浮点计算路径。

已经用改动前版本保存的 160 个 fit，对以下三个变体逐一比较：省略 entry、entry=0、entry=rep(0,n)。160 x 3 的每个完整结果都通过 R identical()，包括节点数组、survival、loglik trace、迭代数和 convergence flag。这是与旧版的回归比较，不只是新实现内部两次调用相等。

验证覆盖：3 种 base、bounded/unbounded support、深度 0/3/6、不同迭代数及 allocated 模式，另含 exact/right-censored/单条记录和正 lower support 边界。

十、对应论文需要修改的逻辑

main_yz.tex 的方法部分应先增加 entry 与 conditional likelihood，然后用 Ntilde_A 统一替换原 expected count 的定义，再解释增广共轭形式和初始化。不能只在代码接口增加 entry 或只裁剪观测区间。

理论部分不能仅把 N 改名为 Ntilde：
* penalized observed objective 需要减去 sum log S_Theta(a_i)；
* 固定树的 EM 论证需要正确的增广 Q、S(entry)>0，以及真正的 M-step maximization 条件；
* 根总数不再固定为 n，旧的 N_A/n 收敛结论需要重新审查；
* 截断下的一致性、可识别性及 entry survival 的正性/可积性条件需要重新证明；
* plug-in Beta distribution 与真实 observed posterior 应保持区别；
* 当前代码的边界 fallback 不能直接冒充论文约束盒上的精确 argmax。

这些理论扩展尚未在本代码任务中证明或合入原论文。新聊天可据本交接继续讨论/修改，但应以用户下一步明确要求为准。
